Политика приватности Voxelify

Действует с 26 ноября 2026 года. English below

Коротко

Voxelify — бесплатный музыкальный плеер с общением. Мы не продаём данные, не показываем рекламу и не следим за тобой ради рекламы.

Что хранится только на твоём устройстве

Музыкальные файлы, история прослушиваний, настройки, профили без входа в аккаунт. Это не уходит в интернет, пока ты сам не включишь облачную копию или вход в аккаунт.

Что хранится в облаке (Google Firebase), если ты вошёл в аккаунт

  • Профиль: @имя, имя, фото, описание, рамки, значки, статус, что ты слушаешь сейчас (можно выключить в настройках профиля). Это видят все.
  • Адрес почты — только для входа, другим людям он не показывается.
  • Список треков, альбомы, избранное, копии настроек — видишь только ты.
  • Личные сообщения — видите вы с собеседником. Они не зашифрованы сквозным шифрованием: технически их может прочитать владелец проекта Firebase. Команда Voxelify читает личные сообщения только по жалобе на конкретное сообщение.
  • Сообщения на серверах — видят участники сервера и команда модерации Voxelify: она может заходить на любой сервер, чтобы удалять запрещённое.
  • Таблица лидеров — сколько ты слушал музыку (можно выключить).
  • Заявки в магазине — какой статус ты заказал.

Звонки и голосовые каналы

Голос и видео идут напрямую между устройствами и в облаке не записываются. Из-за прямого соединения собеседники технически могут узнать IP-адреса друг друга. Если подключён сервер-посредник (TURN), звук идёт через него, но тоже не записывается.

Кому мы передаём данные

Никому не продаём. Данные хранятся у Google (Firebase), вход через Google, GitHub или Discord обрабатывают эти сервисы, сайт размещён на GitHub Pages. Уведомления отправляются через сервисы браузера (Google, Mozilla, Apple, Microsoft) без текста сообщений.

Возраст

Если тебе меньше 13 лет, пользуйся Voxelify только с разрешения родителей. Если ты родитель и хочешь удалить аккаунт ребёнка — напиши нам.

Как удалить данные

Профиль → ⋯ → Настройки профиля → «Удалить профиль». Все данные на устройстве: Настройки → «Удалить все данные». Отметки модерации (бан, SCAM) сохраняются, чтобы их нельзя было обойти.

Связь

Вопросы и просьбы об удалении: github.com/Wisper-2010/Voxelify/issues

Voxelify privacy policy

Effective November 26, 2026.

On your device only: music files, listening history, settings, offline profiles.

In the cloud (Google Firebase), when you sign in: your public profile (username, name, photo, bio, badges, what you listen to now — can be turned off); your e-mail for sign-in only; your track list, albums, favourites and setting copies (only you see them); private messages (you and the other person; not end-to-end encrypted; the Voxelify team reads one only after a report on it); server messages (members and the Voxelify moderation team, which can enter any server to remove prohibited content); leaderboard time (can be turned off); shop orders.

Calls and voice channels go directly between devices and are not recorded; participants can technically learn each other’s IP address.

We do not sell data and show no ads. Data is stored by Google Firebase; the site is hosted on GitHub Pages; sign-in is handled by Google, GitHub or Discord; push notifications carry no message text.

If you are under 13, use Voxelify only with a parent’s permission. Delete your data: Profile → ⋯ → Profile settings → Delete profile; Settings → Delete all data. Moderation marks are kept.

Contact: GitHub issues.
